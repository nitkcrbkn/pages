template<class Writer, size_t PIXEL_COUNT, PixelOrder ORDER = PixelOrder::GRB, class Codec = Spi3BitCodec, bool REVERSED = false>
class led::LEDTape< Writer, PIXEL_COUNT, ORDER, Codec, REVERSED >

NeoPixel LEDテープ

一列に並んだLEDを扱う。論理インデックス0が信号入力側の先頭になる。 テープを逆向きに実装した場合は REVERSED = true とすることで、 論理インデックスの向きだけをコンパイル時に反転できる(実行時コスト0)。

テンプレート引数
Writerビットストリーム送出クラス
PIXEL_COUNTLED数
ORDERチップのch送出順 (既定: GRB = WS2812B)
Codecエンコード方式 (既定: SPI 3bit)
REVERSED論理インデックスを反転するか
// WS2812B 60球をSPI2のDMAで駆動する例
static led::SpiLedWriter<> writer(hspi2);
static led::LEDTape<decltype(writer), 60> tape(writer);
tape.set_brightness(64);
tape.fill(led::colors::BLUE);
tape.show();
