template<class OutputType>
class MotionMode< OutputType >

モーションプロファイル生成

テンプレート引数
OutputTypecalculate() の戻り値型。内部演算は float。

減速計画方式: 速度指令追従

  • Trapezoid: vLimit = sign(e) * min(maxV, -a*dt/2 + sqrt((a*dt/2)^2 + 2*a*|e|)) _velocity を ±maxAcceleration*dt の範囲で vLimit へ追従
  • SCurve: 状態(v, acc)からゴールまでを毎周期逆算 tR = |acc|/j として vPred = v + acc*tR/2 (accを0へ戻した時点の予測速度) dTransit = v*tR + acc^3/(3j^2) (巻き戻し中の走行距離) |e|' = max(0, |e| - dTransit - |vPred|*a/(2j)) vLimit を同式で算出し、targetAcc = clamp((vLimit - vPred)/dt, ±a) を ±maxJerk*dt で追従(Td先行補正 — 現在値でなく予測値で誤差評価)。 速度は加速度の積分。速度・加速度の絶対値クランプを維持

整定条件(複合): Trapezoid : |error| <= maxAcc*dt^2 AND |v| <= maxAcc*dt SCurve : 上記 AND |acc| <= maxJerk*dt 条件が揃ったときのみスナップ整定。速度が残る間はスナップしない。

覚え書き
前提条件:
  • Trapezoid モードは maxVelocity > 0 かつ maxAcceleration > 0 を設定しないと 出力が動かない(エラーは出ない)。
  • SCurve モードは上記に加えて maxJerk > 0 も必要。
