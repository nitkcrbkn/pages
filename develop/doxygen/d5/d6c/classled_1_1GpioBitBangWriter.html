詳解

template<size_t PIN_COUNT = 1>
class led::GpioBitBangWriter< PIN_COUNT >

GPIOを直接叩いてNeoPixelのビットストリームを生成するWriter

SPIが確保できない場合のフォールバック。RawCodec と組み合わせて使う。

警告
リアルタイム制御と同居するファームウェアでは使用しないこと。 「SPIが空いていない」という理由だけで選ぶと制御周期に影響する。 その場合はSPIを1本空けてSpiLedWriterを使うこと。
static GPIOConfig pins[] = {{LED_GPIO_Port, LED_Pin}};
static GPIO_Mgr<1> led_gpio(pins);
static led::GpioBitBangWriter<1> writer(led_gpio);
static led::LEDTape<decltype(writer), 30, led::PixelOrder::GRB,
led::RawCodec> tape(writer);
writer.init();

警告
送出中は割り込みを禁止する(既定)。禁止時間は1球あたり30us、 30球で約0.9ms、60球で約1.8ms、159球では約4.8msに達する。 この間はCAN受信も制御TIMも一切走らない。
DWTサイクルカウンタを使用するためCortex-M3以上が必要。 コアクロックが低いとGPIO操作のオーバーヘッドで タイミングを満たせない(100MHz以上を推奨)。
