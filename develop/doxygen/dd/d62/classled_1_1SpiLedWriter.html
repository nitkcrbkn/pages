詳解

template<bool USE_DMA = true>
class led::SpiLedWriter< USE_DMA >

SPIのMOSIからNeoPixelのビットストリームを送出するWriter

CubeMXでの設定:

  • Mode: Transmit Only Master (MISO/NSSは不要)
  • Frame Format: Motorola / Data Size: 8 Bits / First Bit: MSB First
  • Clock Polarity (CPOL): Low / Clock Phase (CPHA): 1 Edge
  • Prescaler: spi_hal_prescaler(spi_best_divider<Codec>(pclk)) の値 (STM32G4 @ PCLK1=170MHz + Spi3BitCodec なら 64 分周 = 2.66MHz)
  • DMAを使う場合は SPI_TX に DMA を追加すること (Normal / Memory To Peripheral / Increment は Memory のみ / Byte・Byte)
  • NVIC Settings: SPIx TX の DMA割り込みと SPIx global interrupt を有効にする

NVICの優先度: LED更新は制御周期より優先度を低く(=priority値を大きく)すること。 制御TIM / エンコーダ / FDCAN RX より低い優先度に置けば、LEDの送出が それらの応答を悪化させることはない。

警告
DMA転送完了割り込みが有効でないとSPIのstateがREADYへ戻らず、 busy()がtrueのままになって2フレーム目以降が送出されない。 HAL_SPI_Transmit_DMA()はSPIのエラー割り込みも有効にするため、 SPIx global interrupt も併せて有効にすること。
テンプレート引数
USE_DMAtrue でDMA(非同期)、false でブロッキング送信
警告
MOSIラインはアイドル時にLowである必要がある。 送出したbitは必ず0で終わるため転送後はLowに留まるが、初回転送前の レベルは保証されないので外付けプルダウンを推奨する (Codecが先頭に0バイトを1つ入れるが数usぶんにしかならない)。
覚え書き
NeoPixelは5Vロジックのため、3.3V出力ではレベル変換が必要な場合がある。
