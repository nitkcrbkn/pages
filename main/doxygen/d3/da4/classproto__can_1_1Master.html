詳解

任意のデバイスへ命令を送り、任意のデバイスからデータを受信する API

DeviceID を持たないため Data 送信と自動 REQUEST 応答は行わない。 一つのノードが Device と同時にインスタンス化することも可能。

受信コールバックを登録する

全受信メッセージが渡されるため、自身が必要なメッセージかの判定は実装側で行う。 メンバ関数ポインタ形式と関数オブジェクト形式の両方を受け付ける。
