template<size_t MAX_SIZE = 256>
class TelemController< MAX_SIZE >

テレメトリーデータの送受信を行うコントローラークラス

フレームフォーマット: [0xDE][0xFA] + [len_lo][len_hi] + [protobuf data...]

使い方: TelemetryT t; t = telem_ctrl.format(t); t.set_amt(amt_msg); telem_ctrl.send(t);

テンプレート引数
MAX_SIZE送受信バッファの最大サイズ(デフォルト: 256バイト)
