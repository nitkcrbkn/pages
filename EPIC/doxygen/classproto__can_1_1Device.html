template<DeviceType DeviceTYPE>
class proto_can::Device< DeviceTYPE >

DeviceID を持つノードの API

自身のデータ送信と、自分宛の Command 受信を担う。 コンストラクタ時に REQUEST への自動応答と RESET ハンドラが登録される。

テンプレート引数
DeviceTYPEデバイス種別。DeviceSchema の特殊化が必要
