TEST

Catch2（amalgamated版）を使用したユニットテストフレームワーク

実行コマンド

コンパイル

初回は20sほど、2回目からは数秒で完了しそのまま全src/に含まれる全testが実行される

cd test
make test

clean

build/ を消す

make clean

コマンドオプション

make testのあと全てのテストが./build/test_runnerにコンパイルされる。 オプションを使うときはこのファイルを実行する

help

# テスト名で絞り込み
./build/test_runner --help
# テスト名で絞り込み
./build/test_runner "TEST_CASE_pattern"

色々使えるが主なものは: tag検索: 連続して書くとAND[math][can]、カンマを挟めばOR[can],[math] name検索: *でワイルドカードを使い検索可能 *operations

ディレクトリ構造

test/
├── Makefile # ビルド設定
├── README.md # このファイル
├── src/ # テストコード
│ ├── example_test.cpp # サンプルテスト
│ └── subdirectory/ # サブディレクトリも自動検出
│ └── another_test.cpp
└── build/ # ビルド成果物（自動生成）
├── obj/ # オブジェクトファイル
├── libcatch2.a # Catch2ライブラリ
└── test_runner # テスト実行ファイル

テストの書き方

基本的なテストケース

#include <catch_amalgamated.hpp>
TEST_CASE("Basic arithmetic", "[math]") {
REQUIRE(1 + 1 == 2);
CHECK(2 * 3 == 6);
}
TEST_CASE
TEST_CASE("DJI ESC tests", "[dji]")
Definition: test_DJI.cpp:9

セクションを使った構造化

TEST_CASE("Vector operations", "[container]") {
std::vector<int> v;
SECTION("push_back adds elements") {
v.push_back(1);
REQUIRE(v.size() == 1);
REQUIRE(v[0] == 1);
}
SECTION("clear removes all elements") {
v.push_back(1);
v.push_back(2);
v.clear();
REQUIRE(v.empty());
}
}

テストフィクスチャ

struct DatabaseFixture {
DatabaseFixture() {
// セットアップ処理
db.connect();
}
~DatabaseFixture() {
// クリーンアップ処理
db.disconnect();
}
Database db;
};
TEST_CASE_METHOD(DatabaseFixture, "Database queries", "[db]") {
REQUIRE(db.isConnected());
}

パラメータ化テスト

TEMPLATE_TEST_CASE("Container size", "[container]",
std::vector<int>, std::list<int>) {
TestType container;
container.push_back(1);
REQUIRE(container.size() == 1);
}

ビルドシステム

Makefileの主要機能

  • 自動依存関係解決: src/以下のすべての<tt>.cppファイルを自動検出
  • サブディレクトリ対応: 任意の階層のテストファイルに対応
  • インクリメンタルビルド: 変更されたファイルのみ再コンパイル
  • Catch2統合: amalgamated版(Catch2の全て)を初回のみビルド

インクルードパスの設定

Makefileで以下のパスが自動的に設定されます:

  • ../modules: プロジェクトのモジュール
  • ../lib: 外部ライブラリ
  • ../lib/embeddedproto/src: EmbeddedProtoライブラリ
  • ../modules/protocol: プロトコル定義

新しいテストの追加

  1. src/またはそのサブディレクトリに<tt>.cppファイルを作成
  2. Catch2のヘッダーをインクルード
  3. makeでビルド（自動検出されます）
// src/my_new_test.cpp
#include <catch_amalgamated.hpp>
TEST_CASE("My new feature", "[feature]") {
// テストコード
}

ビルドのカスタマイズ

コンパイラフラグを変更する場合は、MakefileのCXXFLAGSを編集:

CXXFLAGS = -std=c++17 -Wall -Wextra -g -O2 # 最適化を追加

トラブルシューティング

ビルドエラー

# クリーンビルドを試す
make clean
make
# Catch2ライブラリを再ビルド
rm -rf build/libcatch2.a build/obj/catch2_main.o
make
